# 📌 Project Overview

DecisionOS is an AI-powered Decision Intelligence Platform that helps governments, organizations, emergency responders, and communities make smarter decisions using live environmental data and Generative AI.

The platform gathers real-time information such as weather, air quality, GPS location, and maps, then uses Google Gemini AI to generate executive-level insights, risk assessments, and decision recommendations.

Instead of only displaying data, DecisionOS transforms information into actionable intelligence.

---

# 🎯 Problem Statement

Communities generate large amounts of real-time data from environmental sensors, weather services, mapping systems, and public information sources.

However, this information is often:

- Disconnected
- Difficult to analyze quickly
- Not transformed into actionable decisions
- Lacking predictive insights

Decision-makers need an intelligent platform capable of analyzing multiple data sources simultaneously and providing AI-powered recommendations in real time.

---

# 💡 Solution

DecisionOS combines multiple live APIs with Google Gemini AI to create an intelligent decision-support platform.

The system automatically:

- Detects the user's location
- Retrieves live weather information
- Monitors Air Quality Index (AQI)
- Displays Google Maps
- Identifies emergency contacts
- Generates executive AI recommendations
- Produces downloadable reports
- Provides predictive decision intelligence

# 🚀 Getting Started

## Clone the Repository

```bash
git clone https://github.com/Krishnapawar222005/DecisionOS.git
```

## Navigate to Project

```bash
cd DecisionOS/frontend
```

## Install Dependencies

```bash
npm install
```

## Configure Environment Variables

Create a `.env.local` file.

```env
GEMINI_API_KEY=YOUR_GEMINI_API_KEY

NEXT_PUBLIC_GOOGLE_MAPS_API_KEY=YOUR_GOOGLE_MAPS_API_KEY

GOOGLE_MAPS_API_KEY=YOUR_GOOGLE_MAPS_API_KEY

NEXT_PUBLIC_OPENWEATHER_API_KEY=YOUR_OPENWEATHER_API_KEY
```

## Run Development Server

```bash
npm run dev
```

## Build Production

```bash
npm run build
```
